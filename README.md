# SecureNation

A colorful, Render-ready full-stack college project.

## Run locally
1. Install Node.js 18+
2. Open this folder in a terminal
3. Run:
   npm install
   npm start
4. Open http://localhost:3000

## Deploy on Render
Create a new **Web Service** from this project/repository.
- Build Command: `npm install`
- Start Command: `npm start`
- Environment: Node

No Vite preview server is used, so the `allowedHosts` error from the screenshot is avoided.

The app includes:
- Colorful responsive SecureNation frontend
- About, Services, Learning and Incident Reporting sections
- Express backend
- `/api/status` health endpoint
- `/api/report` incident-report endpoint
- Render-compatible PORT handling

Important: this is an educational/demo project. Do not collect real passwords, OTPs or sensitive personal information.
